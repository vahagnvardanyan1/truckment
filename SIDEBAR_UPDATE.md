# Sidebar Update - Modernize Style

## Changes Made

### 1. **Section Headers**
- Added "HOME" and "APPS" section headers
- Uppercase, small font (0.75rem)
- Bold (700 weight)
- Gray secondary color
- Letter spacing: 0.5px

### 2. **Navigation Structure**
- Separated HOME section (Modern, Vehicles, Fuel, Maintenance)
- Separated APPS section (Contacts, Chats, Calendar, Email, Tickets, Settings)
- No nested expandable menus - flat structure

### 3. **Styling Updates**
**Active State**:
- Light blue background: `rgba(93, 135, 255, 0.1)`
- Blue text for active items
- Rounded corners: `8px`
- No left border

**Inactive State**:
- No background
- Gray icons and text
- Subtle hover: `rgba(0, 0, 0, 0.04)`

**Badges**:
- "New" badge: Light cyan background `rgba(73, 190, 255, 0.15)` with cyan text
- Number badges: Blue background with white text
- Border radius: 16px
- Height: 24px

### 4. **User Profile Section**
- Added at bottom of sidebar
- Light blue background: `rgba(93, 135, 255, 0.05)`
- Rounded: 12px
- Contains:
  - Avatar (40x40)
  - Name: "Mathew" (subtitle2, 600 weight)
  - Role: "Designer" (caption, gray)
  - Power icon button (blue)

### 5. **Spacing & Typography**
- Item height: 44px
- Padding: px: 2.5, py: 1
- Margin: mx: 1, my: 0.25
- Font size: 0.9375rem
- Font weight: 400 (normal), 600 (active)

### 6. **Colors**
- Active background: `rgba(93, 135, 255, 0.1)` (10% opacity)
- Hover background: `rgba(0, 0, 0, 0.04)` (4% opacity)
- Icons: `text.secondary` (inactive), `primary.main` (active)
- Badge "New": `#49BEFF` color
